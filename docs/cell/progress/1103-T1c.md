# #1103 T1c — publicar, preview y versiones de plantilla de documento

Rama `feature/cell-1103-t1c-publish-preview-versions`, contra `develop`. Sin migración ni cambio de contrato.

## Criterios de aceptación
- [ ] POST publish: Director 200 (nueva versión, el borrador desaparece), Administrativo 403
- [ ] Sin ninguna firma cargada en los firmantes: 422 TEMPLATE_SIGNATURE_MISSING
- [ ] Sin borrador (o igual a la última publicada): 409 TEMPLATE_NOTHING_TO_PUBLISH
- [ ] GET versions / versions/{n}: Administrativo lee, aisladas por tipo, 404 si no existe
- [ ] POST preview: PUBLISHED para Administrativo y Director, DRAFT solo Director, PDF con marca de agua
- [ ] architecture/, ModularityTest, OpenApiSnapshotTest, PermissionGateCoverageTest, AuthorizationMatrixTest, DocsIndexTest
- [ ] Sabotajes atrapados

## Notas
- Publisher compartido con certificados de egreso (`publishDraftOf`), solo cambian el snapshot de firmantes (por tipo de documento) y la regla de publicabilidad (`requirePublishableDocument`: título + al menos un firmante con firma).
- Preview de documentos: el motor actual expande los marcadores que ya conoce; subjectName, examDate, recipient, average y completionPercent siguen literales hasta T1d.
