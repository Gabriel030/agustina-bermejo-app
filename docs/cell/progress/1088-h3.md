# 1088 H3 — Destinos de las tarjetas del Inicio del personal con `?status=PENDING`

## Criterios de aceptación
- [x] `BandejaTramites` lee `status` de la URL; con la prop `pendingStatus` el valor configurado selecciona la pestaña Pendientes y el cambio de pestaña lo escribe o lo quita de la URL
- [x] Sin la prop, `BandejaTramites` no cambia (`status` no se toca)
- [x] `AuthorizationInboxPage` toma la pestaña desde la URL: `status=PENDING` (estado real de `PENDING_STATUSES`) = Pendientes; `tab=history` = Historial; el cambio de pestaña actualiza la URL
- [x] Valor desconocido de `status` se ignora (cae en Pendientes)
- [x] Excepciones elevadas: `/director/aprobaciones/excepciones?status=PENDING` (`pendingStatus="PENDING"` en `DirectorAprobacionesExcepciones`)
- [x] Facturación por autorizar: `/director/aprobaciones/facturacion?status=PENDING`
- [x] Cierres sin acta sin cambios (`?status=TEACHER_CONFIRMED`)
- [x] Tests de StaffHome actualizados a los destinos nuevos
- [x] Tests con sabotaje: quitar la escritura de `status` al volver a Pendientes, ignorar `status` en la resolución de pestaña y quitar la escritura en `AuthorizationInboxPage`, cada uno rompe al menos un test

## Notas
- Hecho: los destinos de las dos tarjetas y la lectura de `status` en las dos bandejas, con tests y sabotajes.
- Desvío de premisa: en ambas pantallas la pestaña por defecto ya es Pendientes (no hay vista "Todas"). Por eso `?status=PENDING` no cambia lo que se ve al entrar: el efecto nuevo es que la URL refleja la pestaña y se conserva al recargar o volver.
- Excepciones: el estado pendiente real es el listado por defecto de `/director-approval-requests` (`REQUESTED`); el mapeo `PENDING` = Pendientes es el de la pantalla.
- Decisión de precedencia: en `BandejaTramites`, `status=PENDING` gana sobre `tab=historial` cuando la prop está configurada.
- Verificación: `npm run lint` sin errores; `npm run build:check` OK; suite completa del frontend en curso.
- Navegador: no verificado (la subtarea no lo pide; la pantalla no cambia en claro/oscuro/móvil).
